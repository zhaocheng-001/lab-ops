## 三、运维模块（新增）权限矩阵

测试方法：4 类账号 × 7 个核心接口

| 接口 | 系统管理员 | 实验室管理员 | 教师 | 学生 |
|------|-----------|-------------|------|------|
| GET /maintenance/faults/my/ | ✅ 0 条（管理员无自己报修） | ✅ 0 条 | ✅ 0 条 | ✅ 2 条 |
| GET /maintenance/faults/ | ✅ 全部 8 条 | ✅ 本实验室 | ✅ 仅本人 | ✅ 仅本人 |
| GET /maintenance/orders/ | ✅ 7 条 | ✅ 6 条 | 🔒 403 | 🔒 403 |
| GET /maintenance/plans/ | ✅ 3 条 | ✅ 3 条 | 🔒 403 | 🔒 403 |
| GET /maintenance/plans/overdue/ | ✅ 3 条 | ✅ 3 条 | 🔒 403 | 🔒 403 |
| GET /maintenance/records/ | ✅ 6 条 | ✅ 6 条 | 🔒 403 | 🔒 403 |
| GET /maintenance/orders/dashboard/ | ✅ 数据 | ✅ 数据 | 🔒 403 | 🔒 403 |

**结论**：权限隔离符合设计预期，学生 / 教师不接触工单管理；实验室管理员限定本实验室范围。

## 七、缺陷与改进

### 7.1 已修复（毕业设计迭代过程中）

| # | 描述 | 修复方案 |
|---|------|---------|
| 1 | `/labs` 页 `useRoute is not defined` | 移除未使用引用 |
| 2 | `/colleges` 页 `.length` 空值崩溃 | 修正响应解包 |
| 3 | `/labs` 列表 403（实验室管理员） | 放宽 `users/simple` 权限 |
| 4 | 不同角色响应结构不统一 | API 层统一包装 `asPagedList` |
| 5 | 通知批量已读后端已实现但前端未调用 | 前端补全 checkbox + batch API |

### 7.2 已知非阻塞问题

- 邮件通知尚未接入 SMTP（仅站内通知）；
- 文件上传走本地存储，未对接对象存储；
- 国际化（i18n）仅中文；
- 移动端为响应式布局，未做 PWA 优化。

> 以上均不影响毕业设计核心演示。
