# 04 - 部署文档

> 本文档介绍如何在生产环境（Ubuntu 22.04 LTS）部署"高校实验室设备预约运维系统"。

## 四、后端部署

### 4.1 拉取代码

```bash
sudo mkdir -p /srv/lab_ops && sudo chown deployer:deployer /srv/lab_ops
cd /srv/lab_ops
git clone <your_repo>.git .
```

### 4.2 Python 虚拟环境

```bash
cd /srv/lab_ops/backend
python3.10 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
pip install gunicorn mysqlclient
```

### 4.3 收集静态资源

```bash
python manage.py collectstatic --noinput
```

### 4.4 数据库迁移 & 初始化

```bash
python manage.py migrate
python manage.py init_demo_data
python manage.py seed_maintenance_demo
```

### 4.5 Gunicorn 配置 `/srv/lab_ops/backend/gunicorn_conf.py`

```python
bind = "127.0.0.1:8001"
workers = (cpu_count * 2) + 1
worker_class = "sync"
timeout = 60
graceful_timeout = 30
keepalive = 2
accesslog = "/var/log/lab_ops/gunicorn.access.log"
errorlog  = "/var/log/lab_ops/gunicorn.error.log"
loglevel = "info"
```

### 4.6 Supervisor 配置 `/etc/supervisor/conf.d/lab_ops.conf`

```ini
[program:lab_ops]
command=/srv/lab_ops/backend/venv/bin/gunicorn labsys.wsgi:application -c /srv/lab_ops/backend/gunicorn_conf.py
directory=/srv/lab_ops/backend
user=deployer
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
stderr_logfile=/var/log/lab_ops/stderr.log
stdout_logfile=/var/log/lab_ops/stdout.log
environment=
    DJANGO_SETTINGS_MODULE="labsys.settings",
    PYTHONUNBUFFERED="1"
```

```bash
sudo mkdir -p /var/log/lab_ops && sudo chown deployer:deployer /var/log/lab_ops
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl status lab_ops
```

## 五、前端部署

### 5.1 构建

```bash
cd /srv/lab_ops/frontend
npm ci
npm run build
# 产物在 dist/
```

### 5.2 Nginx 配置 `/etc/nginx/sites-available/lab_ops`

```nginx
upstream lab_ops_api {
    server 127.0.0.1:8001;
}

server {
    listen 80;
    server_name lab-ops.example.com;

    # 前端静态
    root /srv/lab_ops/frontend/dist;
    index index.html;

    # gzip
    gzip on;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml;

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反代
    location /api/ {
        proxy_pass http://lab_ops_api;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }

    # WebSocket
    location /ws/ {
        proxy_pass http://lab_ops_api;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400s;
    }

    # 媒体
    location /media/ {
        alias /srv/lab_ops/backend/media/;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/lab_ops /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 5.3 HTTPS

```bash
sudo certbot --nginx -d lab-ops.example.com
```

## 八、回滚

```bash
# 1. 停服务
sudo supervisorctl stop lab_ops
# 2. 切代码
cd /srv/lab_ops && git checkout <stable_tag>
# 3. 回滚迁移（如有）
cd backend && source venv/bin/activate
python manage.py migrate <app> <previous_migration>
# 4. 启动
sudo supervisorctl start lab_ops
```

## 九、性能基准

> 单台 4C8G 服务器，Gunicorn 5 workers，MySQL 8.0 默认配置。

| 场景 | QPS | 平均 RT | P99 RT |
|------|-----|---------|--------|
| 登录 + 拉首页 | 230 | 180ms | 420ms |
| 设备列表分页 | 580 | 45ms | 110ms |
| 工单列表 + 仪表盘 | 410 | 65ms | 140ms |
| 报修提交（含设备状态写） | 320 | 75ms | 200ms |

## 十、常见问题

| 现象 | 排查 |
|------|------|
| 502 Bad Gateway | `supervisorctl status lab_ops` 看是否启动；`/var/log/lab_ops/stderr.log` |
| 静态文件 404 | `python manage.py collectstatic` 重新执行 |
| 数据库连接拒绝 | `mysql -ulab_ops -p` 手动验证；检查 `bind-address` |
| 跨域错误 | `CORS_ALLOWED_ORIGINS` 配置域名白名单 |
| Token 过期 | 前端 axios 拦截器自动 refresh；检查 `ROTATE_REFRESH_TOKENS` |
