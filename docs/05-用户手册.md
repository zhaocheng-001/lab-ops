## 二、学生操作指南

### 2.1 浏览设备

- 左侧菜单点击"设备与实验室 → 设备台账"；
- 可按实验室 / 分类 / 状态筛选；
- 点击设备行查看详情（参数、状态、使用记录）。

### 2.2 预约设备

1. 进入"设备台账"；
2. 找到可用设备，点击"预约"；
3. 填写：开始时间、结束时间（系统会自动校验是否与现有预约冲突）；
4. 提交后状态变为"待审批"，等待实验室管理员审批。

> 单次预约最长时长由设备的 `max_booking_hours` 限制。

### 2.3 跟踪审批进度

- 左侧菜单"预约管理 → 我的预约"；
- 每条预约显示当前状态和操作按钮：
  - 待审批 → "撤回"
  - 已通过 → "签到"
  - 已签到 → "签退 + 评价"

### 2.4 故障报修

1. 左侧菜单"设备运维 → 设备报修"；
2. 点击右上角"发起报修"；
3. 选择故障设备、故障类别、严重程度；
4. 填写故障描述（建议至少 5 个字） → 提交；
5. 提交后可在"我的报修"查看处理进度。

## 三、教师操作指南

### 3.1 预约审批

- 进入"预约管理 → 待我审批"；
- 点击记录查看详情（含申请人、历史使用、信誉）；
- 三个操作：
  - **通过** → 直接放行
  - **驳回** → 填写理由
  - **转派** → 指定其他审批人

### 3.2 实验室使用统计

- 进入"统计分析" → 选择"本实验室"维度；
- 视图：使用率趋势 / 设备排行 / 故障率；
- 支持导出 CSV / Excel。

## 四、实验室管理员操作指南

### 4.1 设备管理

#### 4.1.1 新建设备

"设备与实验室 → 设备台账 → 新建"：
- 基础信息：名称、资产编号、分类、所属实验室
- 规格：购置日期、最大预约时长、安装位置
- 启用：默认启用；停用后无法被预约

#### 4.1.2 修改设备状态

设备详情页 → "修改状态"：
- 可用 / 已预约 / 维修中 / 报废
- 每次变更写入操作日志

### 4.2 维修工单（核心）

1. **来源**：学生/教师报修后自动转入；也可手动新建（计划维护、主动维护）；
2. **入口**："设备运维 → 维修工单"；
3. **指派**：点"指派" → 选择处理人 → 保存；
4. **开始**：处理人点"开始"；
5. **完成**：处理人填写"处理方案"（必填）、"更换配件"、"维修费用" → 提交；
6. **验收**：管理员点"验收" → 工单关闭。

> 设备的"维修中"状态会在工单完成后自动回到"可用"。

### 4.3 维保计划

"设备运维 → 维保计划"：
- 列表显示名称、周期、下次到期、负责人、完成率；
- 逾期计划自动标红 + 显示逾期天数；
- 点击"执行巡检" → 选"正常/异常/需维修" → 提交；
- 若选"需维修"，**自动派生一条维修工单**。

### 4.4 巡检记录

"设备运维 → 巡检记录"：
- 支持按实验室 / 结果筛选；
- 顶部 4 张统计卡片（总 / 正常 / 异常 / 需维修）；
- "新增巡检" → 选设备、关联计划、填写结果。

### 4.5 审批待办

"预约管理 → 待我审批" 处理本实验室的预约。

## 五、系统管理员操作指南

### 5.1 用户管理

- 入口："系统管理 → 用户管理"；
- 可按角色 / 学院 / 班级筛选；
- 操作：新建 / 编辑 / 停用 / 重置密码；
- 必填：用户名、真实姓名、角色、学院、初始密码。

### 5.2 学院与班级

- 学院列表（系统初始化时已建好）；
- 班级管理：可批量导入（CSV 模板下载）。

### 5.3 操作日志

- 入口："系统管理 → 操作日志"；
- 顶部"操作类型分布"标签可点击筛选；
- 支持按操作人 / 模块 / 时间段查询。

### 5.4 全局统计

- 入口："统计分析 → 资产总览"；
- 显示：在册用户 / 实验室 / 设备 / 累计预约 / 履约完成率；
- 进入"按设备分类"、"申请人排行"查看细粒度数据。

## 六、常见操作 FAQ

### 6.1 报修后多久能处理？

- 一般 ≤ 24 小时（系统会在"维修工单 → 运维仪表盘"显示"超 24h 未响应"数量）；
- 紧急（P0）工单建议 2 小时内开始处理。

### 6.2 设备"维修中"状态会影响预约吗？

是的，"维修中"的设备在学生端列表中**不可预约**，需等工单完成 / 取消后回到"可用"才恢复。

### 6.3 维保计划多久执行一次？

由管理员配置，常见：
- 高频精密仪器：每月
- 计算机 / 网络设备：每季度
- 普通教学设备：每半年

### 6.4 找不到某个菜单？

按角色权限显示：
- 学生看不到"系统管理"、"维修工单"、"维保计划"等；
- 实验室管理员看不到"用户管理"等跨实验室功能。

### 6.5 误操作如何撤销？

- 预约：状态为"待审批"时可撤回；已开始的可联系审批人驳回；
- 报修：状态为"待派单"时可联系管理员驳回；
- 工单：状态为"待处理/处理中"时可取消（需填写原因）；
- 已完成的工单不可撤销，但可新建"返修"工单。

## 七、移动端

系统使用 Vue 3 + Element Plus，**响应式布局**：
- 宽度 ≤ 768px：侧边栏自动收起为汉堡菜单；
- 表格横向滚动，操作按钮保留；
- 关键操作（签到、报修）有独立移动优化。

推荐浏览器：Chrome 90+ / Edge 90+ / Safari 14+。
